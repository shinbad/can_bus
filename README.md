# 🚌 프로젝트 개요
본 프로젝트는 최근 자동차의 네트워크화 증가로 CAN bus의 보안 위협이 대두 됨에 따라, 정교한 머신러닝 알고리즘과 데이터 전처리 기법을 통해 보다 신뢰성 높은 보안 시스템 구축을 목표로 합니다.
---

# 🚏 ASK 2024 논문 경진 대회

- **논문 제목**: 휴리스틱과 XGBoost 를 활용한 비정상 CAN 메시지 탐지
- **주요 역할:** 논문 작성 및 실험
- **게재처**: 한국정보처리학회 학술대회논문집
- **논문 링크**: https://kiss.kstudy.com/Detail/Ar?key=4096826

# 💽 데이터 개요

## 📂 공개 Dataset

### 🚗 고려대 해킹대응 기술 연구실

- **Dataset**: Car Hacking:Attack&Defense Challenge 2021 Dataset (Revision)
- **출처**: http://ieee-dataport.org/open-access/car-hacking-attack-defense-challenge-2020-dataset
- **차량 모델**: 현대 아반떼 CN7
- **포함 데이터**:
    - 정상 데이터
    - 공격 유형 데이터 (Flooding, Fuzzing, Replay, Spoofing)
    - Train/Test Set 포함

### 🚙 현대 아반떼의 DBC 데이터

- **출처**: https://github.com/commaai/opendbc
- **내용**: 현대 아반떼 CN7의 CAN 메시지 데이터베이스
